# 수면 중 산소포화도·피부온도 측정 간격 확인 도구

삼성헬스에 저장된 수면 중 **산소포화도·피부온도** 기록을 그대로 읽어, 기록 구간과 세부 측정값(SERIES_DATA) 사이 간격을 계산한다.
사내 SDK는 기록의 대표값만 넘겨주므로, 이 도구는 삼성헬스 Data SDK를 직접 호출한다. **측정용 브랜치 전용 — main 에 합치지 않는다.**

- 브랜치: `tool/samsung-health-interval-probe` (origin/main 기준)
- 코드: `src/main/java/.../IntervalProbe.kt`, 화면 버튼은 `MainActivity.kt` 의 "[디버그] 수면 산소포화도·피부온도 간격 분석 (30일)"

## 준비물

| 항목 | 조건 |
|---|---|
| 워치 | 산소포화도: 갤럭시워치4 이상 · **피부온도: 워치5 이상** (워치4·FE는 온도 센서 없음) |
| 워치 설정 | 삼성헬스 → 수면 → 고급 측정 → **수면 중 혈중 산소**, **수면 중 피부 온도** 켜기 |
| 측정 | 워치를 찬 채로 하룻밤 수면 (자동 감지, 짧은 낮잠은 안 잡힐 수 있음). 아침에 폰 삼성헬스와 동기화 확인 |
| 폰 삼성헬스 | **개발자 모드 + 데이터 읽기 ON** (설정 → 삼성헬스 정보 → 버전 10회 탭). 꺼져 있으면 오류 없이 빈 결과가 옴 |

## 실행

```bash
git checkout tool/samsung-health-interval-probe
./gradlew :polihealth-samsung-health-data-android-sdk-example:installDebug
```

1. 앱 실행 → **권한 요청** (4개 항목 승인)
2. 보라색 **간격 분석** 버튼
3. 결과는 화면과 logcat 에 같이 남는다

```bash
adb logcat -s IntervalProbe:I
```

## 결과 읽는 법

```
===== 산소포화도: 레코드 1건 (최근 30일)
[산소포화도 #0] 10-21 01:30:00 ~ 10-21 07:00:00 (330분) series=33건 간격(초) min=600 med=600 max=620 (n=32) · 항목길이(초) ... · 기기=...
    · 10-21 01:30:00~10-21 01:31:00 97.6
[산소포화도] 레코드 시작 간격(초) ...
```

- `~` 앞뒤: 삼성헬스 기록 1건(보통 수면 1회)의 시작·종료
- `series=N건`: 그 기록 안의 세부 측정값 개수
- `간격(초)`: 세부 측정값 시작 시각 사이 간격 → **이게 측정 인터벌**
- `항목길이(초)`: 세부 측정값 하나가 몇 초 동안 잰 값인지
- 처음 4개 세부 측정값은 원본 그대로 출력

## 참고 (지금까지 확인된 것)

- 산소포화도: 실측 자료상 수면 중 약 10분 단위 (스마트워치 취득 매트릭스 03 시트). 공식 문서는 "수면 중 연속 측정"만 명시
- 피부온도: 공식 문서·매트릭스 모두 간격 미명시 → 이 도구로 확인 필요
- 2026-10-20 워치4로 시도: 피부온도 메뉴 자체가 없음(센서 없음), 수면 기록 없어 0건
